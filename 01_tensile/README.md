\# Uniaxial Tensile Simulation



This folder contains a demonstration workflow for performing uniaxial

tensile simulations of AlxCoCrFeNi high-entropy alloys using LAMMPS.



\## Folder Contents



\- `input/` — LAMMPS input scripts

\- `postprocessing/` — Jupyter notebooks used for data analysis

\- `sample\_data/` — small example datasets

\- `sample\_results/` — representative processed figures



Detailed simulation parameters will be documented later.
